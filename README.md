# Подходящие площадки

Простая страница для родителей: пять ресторанов Ростова-на-Дону, реальные фотографии залов, короткое описание, стоимость на выбранную компанию и меню.

## Версия 2 — 6 ноября 2026

По просьбе пользователя полностью изменён интерфейс: крупный жирный шрифт Arial (основной текст 23–26 px), синяя палитра, последовательные карточки, реальные фото. Таблицы, формулы, рекомендации и длинные списки вопросов убраны с основного экрана. Источники раскрываются внизу.

Десять фото сохранены локально в WebP (всего около 1,7 МБ), без внешних запросов при просмотре. Первое фото загружается сразу, остальные — лениво. Оригиналы и подписи записаны в js/gallery-data.js и разделе источников. Фото взяты с официальных сайтов Террасы 180, Radisson и Петровского причала, а также с каталогов Мой Банкет и АрендаЗала для Теплицы и нижней палубы Причала 25. Размещение фотографий запрошено пользователем; открытая лицензия не установлена, разрешение правообладателей не заявляется.

## Работа

Открыть index.html либо раздать папку любым статическим сервером. HTML содержит все карточки и фотографии и доступен без JavaScript. JavaScript меняет фото и расчёты. Без сервера, аналитики, регистрации, форм оплаты и библиотек.

- index.html — простые карточки и раскрывающиеся источники.
- css/style.css — адаптивный крупный интерфейс и печать.
- js/main.js — изменение гостей, дня и дополнительных расходов, галерея, печать, ссылка.
- js/calculator.js — независимая расчётная логика без изменений тарифных моделей.
- js/gallery-data.js — подписи и происхождение фотографий.
- js/data.js — исходные исследовательские записи первой версии, не загружаются страницей.

## Стоимость

Цены — опубликованные ориентиры, а не подтверждённые тарифы 2027. Еда не представляется гарантированным набором: состав меню, напитки и обязательные доплаты требуют согласования. Для Петровского сохраняется диапазон двух тарифов, для Причала и Петровского 10% показаны только как условный сценарий. Отдельные залы Radisson не рассчитываются по цене FireLake.

Число гостей 21–50, по умолчанию 21. День меняет расчёты Теплицы и Террасы. Бюджет и допрасходы убраны в необязательный раскрывающийся блок. Формулы посетителям не показываются. Предельная вместимость учитывается. Неизвестные расходы не равны нулю.
