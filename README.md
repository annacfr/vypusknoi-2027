# Выпускной 2027 · Ростов-на-Дону

Независимая подборка пяти заведений для родителей 11 класса. Статический HTML/CSS/JavaScript, без библиотек, платных API, аналитики, форм и хранения данных. GitHub Pages: https://annacfr.github.io/vypusknoi-2027/ . Публикация подтверждена 06.11.2026: сборка Pages `built`, анонимные запросы страницы и всех пяти CSS/JS/SVG-ресурсов — HTTP 200. Подробности и ограничения проверок — в `VERIFICATION.md`.

## Запуск и структура

Открыть `index.html` либо запустить локальный статический сервер. Файлы имеют относительные пути и работают под `/vypusknoi-2027/`.

- `js/data.js` — рестораны, источники, меню, статусы 11 вопросов.
- `js/calculator.js` — чистая арифметика; `js/main.js` — вывод и взаимодействия.
- `css/style.css` — адаптивная и печатная версии.
- `images/` — собственный SVG-знак. Чужие фотографии не скопированы.

## Расчётные модели

Для N гостей, до необязательных расходов:

- Теплица: `max(100000 / 150000, N*3500)*1.05` (будни / выходные).
- Терраса: `max(120000 / 140000, N*4500)*1.10`.
- Причал: `N*4500`, отдельно сценарий `N*4500*1.10`: сервис найден в «Горько!», но не подтверждён рестораном. Минимальный заказ неизвестен.
- Radisson: `N*5000+40000` — исключительно предварительный сценарий ресторана. Цены не перенесены на конференц-залы. Скидки по аренде не применены.
- Петровский: диапазон `N*3500 … N*5000`, отдельно вариант с 10% обслуживания. Ни закрытие, ни аренда не известны.

Обслуживание начисляется на ресторанную часть, выбранные пользователем дополнительные расходы прибавляются затем. Ни одна сумма не обозначена окончательной. Остатки и превышения условны до уточнения неизвестных расходов. При N больше указанной вместимости есть предупреждение. Конференц-вместимость Radisson не выдаётся за банкетную.

## Публикация

Ветка `main`, GitHub Pages из корня `/`. `.nojekyll` отключает Jekyll. Сборка и сервер не нужны. Все внешние ссылки открываются с `noopener noreferrer`. Кнопка «Поделиться» копирует канонический URL; при отказе Clipboard API выводит его для ручного копирования. Печать раскрывает подробности и сохраняет ссылки источников.
