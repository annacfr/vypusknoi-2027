# Фотографии

10 сжатых реальных фотографий. По просьбе пользователя заменены прежние типографические заглушки. Файлы и исходные URL перечислены в ../js/gallery-data.js. Кадры проверены визуально: кафе Теплица, основной зал Террасы 180 (с праздничным оформлением), закрытая нижняя палуба Причала 25, FireLake, Каминный и Золотой залы. Открытые террасы не использованы. Правообладатели не меняются, открытая лицензия не заявляется.
